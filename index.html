C971 - Student Term Tracker

A .NET MAUI Android app for tracking academic terms, courses, and assessments. Built as part of the WGU D424 Software Engineering Capstone.

Features

  • Track academic terms with start and end dates
  • Manage courses within each term, including status and instructor info
  • Schedule and track objective and performance assessments
  • Set date notifications for upcoming courses and assessments
  • Share course notes via email
  • Search across all terms, courses, and assessments
  • View a full report of all academic data
